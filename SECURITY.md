# Security policy

Only the latest chart release receives fixes.

Report vulnerabilities in the chart through [GitHub security advisories](https://github.com/terrakube-io/terrakube-helm-chart/security/advisories/new). Do not open a public issue.

Vulnerabilities in the Terrakube API, executor, registry or UI go to [terrakube-io/terrakube](https://github.com/terrakube-io/terrakube/security/advisories/new).
